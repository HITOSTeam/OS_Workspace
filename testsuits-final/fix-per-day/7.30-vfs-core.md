# 统一 VFS 核心批次记录

本批次先建立不依赖路径字符串翻译的对象层，尚未切换现有 pathname syscall：

- `VfsFileSystem`、`VfsNode`、positive `Dentry` cache；
- `VfsPath { mount, dentry }`、`PinnedPath`、`FileDescription`、`FsStruct`；
- 使用 `(parent_mount_id, dentry_id)` 的 mount graph，支持 overmount stack、
  bind subroot、move、remount、normal/lazy umount；
- REF-walk 路径解析，覆盖 `.`、`..`、绝对/相对 symlink、40 层上限、
  trailing slash、`BENEATH`、`IN_ROOT`、`NO_XDEV`、magic link；
- ext4 节点 adapter；
- 独立真实 TmpFs：稀疏页、容量/inode 限制、hard link、rename、unlink 后
  生命周期、xattr、设备节点和真实 `statfs`。

主机对象测试曾捕获并修复一个 dentry 生命周期问题：父 dentry 和 cache 都是
弱引用时，向下遍历后父对象会释放，使 `..` 返回失败。最终采用“子 dentry 强
引用父 dentry、cache 弱引用 dentry”，不存在引用环。
